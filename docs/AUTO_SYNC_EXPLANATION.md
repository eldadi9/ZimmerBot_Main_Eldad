# 🔄 סנכרון אוטומטי - הסבר מפורט

## 📋 מה זה סנכרון אוטומטי?

הסנכרון האוטומטי רץ ברקע כל **5 דקות** (ברירת מחדל) ומעדכן אוטומטית:
- **Calendar → DB**: מזהה שינויים ביומנים (שם לקוח, מייל, טלפון, תאריכים) ומעדכן את ה-DB
- **Sheets → DB**: מזהה שינויים ב-Google Sheets (צימרים חדשים, עדכוני מידע) ומעדכן את ה-DB

## 🤔 למה כפתורי הסנכרון הידניים שימושיים?

למרות שיש סנכרון אוטומטי, **כפתורי הסנכרון הידניים חשובים מאוד** למקרים הבאים:

### 1. **סנכרון מיידי** ⚡
- **מתי**: כשצריך לעדכן **עכשיו** ולא לחכות 5 דקות
- **דוגמה**: הוספתי צימר חדש ב-Sheets ורוצה שהוא יופיע מיד במערכת

### 2. **בדיקות וניפוי באגים** 🔍
- **מתי**: כשצריך לבדוק סנכרון ספציפי או לפתור בעיה
- **דוגמה**: "למה ההזמנה לא עודכנה?" → בודקים ידנית מה קורה בסנכרון

### 3. **התאוששות אחרי בעיה** 🔧
- **מתי**: אחרי בעיה טכנית או שגיאה, צריך לסנכרן מחדש ידנית
- **דוגמה**: שרת היה כבוי 2 שעות → אחרי שהוא חוזר, רצוי לסנכרן ידנית

### 4. **בקרה מדויקת** 🎯
- **מתי**: לסנכרן רק לכיוון אחד (Sheets → DB או DB → Calendar)
- **דוגמה**: רק עדכנתי ב-DB, לא צריך לסנכרן מ-Sheets

### 5. **טווח תאריכים מותאם** 📅
- **מתי**: לסנכרן תקופה ספציפית (לא רק 30 יום אחורה ברירת מחדל)
- **דוגמה**: "סנכרן לי את כל ההזמנות מ-2025" → משנים את `days_back` ו-`days_forward`

### 6. **Booking ספציפי** 🎫
- **מתי**: לסנכרן רק הזמנה אחת ספציפית
- **דוגמה**: עדכנתי הזמנה אחת ב-DB → סנכרן רק אותה ל-Calendar (לא את כל ההזמנות)

### 7. **ניטור ודיווח** 📊
- **מתי**: לראות בדיוק מה קרה בכל סנכרון (כמה הועתקו, כמה עודכנו, כמה שגיאות)
- **דוגמה**: יומן הסנכרון מציג את כל הפעולות והתוצאות

## 🔄 איך הסנכרון האוטומטי עובד?

### Calendar → DB (אוטומטי כל 5 דקות)
1. בודק את כל האירועים ביומנים של כל הצימרים
2. משווה עם ההזמנות ב-DB
3. אם יש שינוי (שם, מייל, טלפון, תאריכים, צימר) → מעדכן את ה-DB
4. אם יש אירוע חדש ביומן → יוצר הזמנה חדשה ב-DB

### Sheets → DB (אוטומטי כל 5 דקות)
1. קורא את כל הצימרים מ-Google Sheets
2. משווה עם הצימרים ב-DB
3. אם יש שינוי (שם, אזור, מחירים, תכונות, תמונות, כתובת) → מעדכן את ה-DB
4. אם יש צימר חדש ב-Sheets → יוצר צימר חדש ב-DB

## ⚙️ הגדרות הסנכרון האוטומטי

- **ברירת מחדל**: פעיל, כל 5 דקות
- **שינוי תקופה**: אפשר לשנות עם משתנה סביבה `AUTO_SYNC_INTERVAL_MINUTES`
- **הפעלה/כיבוי**: אפשר להפעיל/לכבות דרך ה-UI (כפתור "עצור/הפעל סנכרון אוטומטי")

## 🎯 סיכום

**כפתורי הסנכרון הידניים הם קריטיים** כי הם נותנים:
- ✅ שליטה מיידית
- ✅ גמישות (טווח תאריכים, כיוון ספציפי, booking ספציפי)
- ✅ יכולת לפתור בעיות
- ✅ שקיפות מלאה (לראות בדיוק מה קורה)

**הסנכרון האוטומטי הוא תוספת מעולה** כי הוא:
- ✅ שומר על מידע מעודכן ללא התערבות
- ✅ חוסך זמן (לא צריך לזכור לסנכרן)
- ✅ מגלה שינויים שגולשו/נשכחו
