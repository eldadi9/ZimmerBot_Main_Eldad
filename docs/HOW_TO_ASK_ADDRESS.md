# 📍 איך לבקש כתובת מהסוכן?

**תאריך יצירה:** 11 ינואר 2026

---

## ❓ מה הבעיה?

הסוכן **יודע** להציג כתובות וקישורים ל-Google Maps ו-Waze, אבל צריך לבקש ממנו **בצורה נכונה**.

---

## ✅ איך לבקש כתובת מהסוכן?

### 1. תחילה צריך לבחור צימר

**שלב 1:** בחר צימר

```
"איזה צימרים יש?"
"רשימת צימרים"
"מה הצימרים?"
```

**שלב 2:** בחר צימר ספציפי

```
"ZB01"
"צימר 1"
"[שם הצימר]"
```

**שלב 3:** בקש כתובת

```
"איפה הצימר?"
"מה הכתובת?"
"איך מגיעים?"
"שלח לי מיקום"
"גוגל מפות"
"וייז"
"מפה"
```

## ⚠️ מה לא עובד?

### ❌ בקשה ללא צימר:

**משתמש:**
```
"מה הכתובת?"
```

**סוכן:**
```
אני לא בטוח על איזה צימר אתה שואל. אנא ציין את מספר או שם הצימר.
```

**פתרון:** תחילה בחר צימר!

---

### ❌ אין כתובת ב-Google Sheets:

**משתמש:**
```
"איפה ZB01?"
```

**סוכן:**
```
❌ לא מצאתי כתובת לצימר זה בגוגל שיטס. 
אנא פנה לבעלים לקבלת פרטים או עדכן את הכתובת ב-Google Sheets.
```

**פתרון:** עדכן כתובת ב-Google Sheets!

## 🔧 אם זה עדיין לא עובד

### בדוק 1: יש כתובת ב-Google Sheets?

**עמודות:**
- `address` (כתובת מלאה)
- או `street_name`, `city`, `postal_code` (שדות נפרדים)

**פורמט מומלץ:**
```
רחוב + מספר, עיר, מיקוד
```

**דוגמה:**
```
רחוב הפרחים 15, כפר תבור, 15247
```

---

### בדוק 2: סנכרן מ-Google Sheets ל-DB

**Admin Panel → Sync:**
- לחץ על **"Sheets → DB"**
- זה יעדכן את הכתובת ב-DB

---

### בדוק 3: בחרת צימר?

**חשוב:** צריך לבחור צימר **לפני** לבקש כתובת!

**שיחה נכונה:**
```
1. "איזה צימרים יש?"
2. "ZB01"
3. "איפה הצימר?"
```

**שיחה לא נכונה:**
```
1. "איפה הצימר?"  ← לא עובד! צריך לבחור צימר תחילה
```
