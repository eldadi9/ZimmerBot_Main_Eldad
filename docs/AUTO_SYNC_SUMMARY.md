## 📋 למה כפתורי הסנכרון הידניים שימושיים?

### 1. **סנכרון מיידי** ⚡
כשצריך לעדכן **עכשיו** ולא לחכות 5 דקות.

**דוגמה**: הוספתי צימר חדש ב-Sheets ורוצה שהוא יופיע מיד במערכת.

### 2. **בדיקות וניפוי באגים** 🔍
כשצריך לבדוק סנכרון ספציפי או לפתור בעיה.

**דוגמה**: "למה ההזמנה לא עודכנה?" → בודקים ידנית מה קורה בסנכרון.

### 3. **התאוששות אחרי בעיה** 🔧
אחרי בעיה טכנית או שגיאה, צריך לסנכרן מחדש ידנית.

**דוגמה**: שרת היה כבוי 2 שעות → אחרי שהוא חוזר, רצוי לסנכרן ידנית.

### 4. **בקרה מדויקת** 🎯
לסנכרן רק לכיוון אחד (Sheets → DB או DB → Calendar).

**דוגמה**: רק עדכנתי ב-DB, לא צריך לסנכרן מ-Sheets.

### 5. **טווח תאריכים מותאם** 📅
לסנכרן תקופה ספציפית (לא רק 30 יום אחורה ברירת מחדל).

**דוגמה**: "סנכרן לי את כל ההזמנות מ-2025" → משנים את `days_back` ו-`days_forward`.

### 6. **Booking ספציפי** 🎫
לסנכרן רק הזמנה אחת ספציפית.

**דוגמה**: עדכנתי הזמנה אחת ב-DB → סנכרן רק אותה ל-Calendar (לא את כל ההזמנות).

### 7. **ניטור ודיווח** 📊
לראות בדיוק מה קרה בכל סנכרון (כמה הועתקו, כמה עודכנו, כמה שגיאות).

**דוגמה**: יומן הסנכרון מציג את כל הפעולות והתוצאות.

## 🔄 איך זה עובד?

### Startup Event
כשהשרת מתחיל, המערכת:
1. מנסה להתקין APScheduler
2. יוצרת background job שרץ כל 5 דקות
3. מפעילה את הסנכרון האוטומטי

### Auto-Sync Task
כל 5 דקות (ברירת מחדל), המערכת:
1. **Calendar → DB**:
   - בודקת את כל האירועים ביומנים
   - משווה עם ההזמנות ב-DB
   - מעדכנת שינויים (שם, מייל, טלפון, תאריכים, צימר)
   - יוצרת הזמנות חדשות אם יש אירועים חדשים

2. **Sheets → DB**:
   - קוראת את כל הצימרים מ-Google Sheets
   - משווה עם הצימרים ב-DB
   - מעדכנת שינויים (שם, אזור, מחירים, תכונות, תמונות, כתובת)
   - יוצרת צימרים חדשים אם יש צימרים חדשים ב-Sheets

### Shutdown Event
כשהשרת נסגר, המערכת:
1. עוצרת את ה-scheduler
2. מסיימת את כל המשימות הרצות

## 🚀 איך להתקין ולהפעיל

1. **התקן APScheduler**:
   ```bash
   pip install -r requirements.txt
   ```

2. **הפעל את השרת**:
   ```bash
   python -m uvicorn src.api_server:app --reload
   ```

3. **בדוק שהסנכרון האוטומטי רץ**:
   - תראה הודעת startup: `✅ Auto-sync scheduler started (interval: 5 minutes)`
   - כל 5 דקות תראה הודעת סנכרון בטרמינל

4. **ניהול דרך UI**:
   - פתח `tools/features_picker.html`
   - Admin Panel → Sync
   - תראה סטטוס סנכרון אוטומטי
   - כפתור להפעיל/לכבות

## ⚙️ הגדרות

- **ברירת מחדל**: פעיל, כל 5 דקות
- **שינוי תקופה**: הגדר משתנה סביבה `AUTO_SYNC_INTERVAL_MINUTES=10` (לדוגמה, כל 10 דקות)
- **הפעלה/כיבוי**: דרך UI (כפתור "עצור/הפעל סנכרון אוטומטי")
