# 📍 מדריך כתובות - מה הסוכן יודע ואיך לרשום

**תאריך יצירה:** 11 ינואר 2026

---

## 🎯 מה הסוכן יודע על כתובות?

הסוכן מזהה בקשות למיקום/כתובת דרך מילות מפתח:
- **עברית:** "מיקום", "איפה", "כתובת", "מפה", "גוגל מפות", "וייז", "איך מגיעים", "שלח מיקום", "שלח לי מיקום"
- **אנגלית:** "location", "address", "maps", "waze"

כשמבקשים מיקום, הסוכן:
1. ✅ מחפש כתובת ב-Google Sheets
2. ✅ מציג כתובת מלאה
3. ✅ יוצר קישורים ל-Google Maps ו-Waze (אוטומטית)
4. ✅ מציג הודעה אם אין כתובת

---

## 📝 איך לרשום כתובת ב-Google Sheets?

### שיטה 1: כתובת מלאה (מומלץ) ✅

**עמודה:** `address` (או `Address`)

**דוגמה:**
```
רחוב הפרחים 15, כפר תבור, 15247
```

**יתרונות:**
- ✅ פשוט ונוח
- ✅ הסוכן משתמש ישירות
- ✅ קל לעדכון

---

### שיטה 2: שדות נפרדים (גמיש יותר)

**עמודות:**
- `street_name` (או `Street name + number`) - שם רחוב + מספר
- `city` (או `City`) - עיר
- `postal_code` (או `Postal code`) - מיקוד

**דוגמה:**
```
street_name: "רחוב הפרחים 15"
city: "כפר תבור"
postal_code: "15247"
```

**יתרונות:**
- ✅ גמיש יותר (אפשר לחפש לפי עיר)
- ✅ הסוכן בונה כתובת מלאה אוטומטית
- ✅ נוח למיון/סינון

---

### שיטה 3: כתובת + קישורים ישירים (הכי מומלץ) ⭐

**עמודות:**
- `address` - כתובת מלאה
- `google_maps_url` - קישור ישיר ל-Google Maps (אופציונלי)
- `waze_url` - קישור ישיר ל-Waze (אופציונלי)

**דוגמה:**
```
address: "רחוב הפרחים 15, כפר תבור, 15247"
google_maps_url: "https://www.google.com/maps/search/?api=1&query=רחוב+הפרחים+15+כפר+תבור"
waze_url: "https://waze.com/ul?q=רחוב+הפרחים+15+כפר+תבור"
```

**יתרונות:**
- ✅ כתובת מלאה + קישורים מהירים
- ✅ אם אין קישורים, הסוכן יוצר אוטומטית
- ✅ הכי נוח למשתמש

---

## 🔍 מה הסוכן עושה עם הכתובת?

### 1. חיפוש כתובת

הסוכן מחפש כתובת ב-3 דרכים (בסדר הזה):

1. **כתובת מלאה** (`address`)
   ```python
   full_address = cabin.get('address') or ''
   ```

2. **בנייה משדות נפרדים** (אם אין כתובת מלאה)
   ```python
   street = cabin.get('street_name') or ''
   city = cabin.get('city') or ''
   postal_code = cabin.get('postal_code') or ''
   full_address = ', '.join([street, city, postal_code])
   ```

3. **אם אין כתובת בכלל:**
   ```
   ❌ לא מצאתי כתובת לצימר זה בגוגל שיטס. 
   אנא פנה לבעלים לקבלת פרטים או עדכן את הכתובת ב-Google Sheets.
   ```

---

### 2. יצירת קישורים למפות

הסוכן יוצר קישורים אוטומטית:

**אם יש קישורים ב-Sheets:**
- משתמש ב-`google_maps_url` ו-`waze_url` ישירות

**אם אין קישורים:**
- בונה אוטומטית מ-הכתובת:
  ```python
  google_maps_url = f"https://www.google.com/maps/search/?api=1&query={encoded_address}"
  waze_url = f"https://waze.com/ul?q={encoded_address}"
  ```

---

### 3. תצוגה למשתמש

כשמבקשים מיקום, הסוכן מציג:

```
📍 מיקום הצימר [שם הצימר]:

כתובת: רחוב הפרחים 15, כפר תבור, 15247

🗺️ קישורים למפות:
• 🗺️ Google Maps
• 🧭 Waze

💡 לחץ על הקישורים כדי לפתוח במפה או באפליקציית הניווט שלך.
```

---

## ✅ המלצות לרישום כתובות

### 1. פורמט מומלץ:

```
רחוב + מספר, עיר, מיקוד
```

**דוגמאות:**
- `רחוב הפרחים 15, כפר תבור, 15247`
- `דרך הגליל 42, צפת, 13100`
- `שדרות הרצל 8, תל אביב, 61000`

---

### 2. מה לא לעשות:

❌ **לא לרשום:**
- רק שם רחוב בלי מספר
- רק עיר בלי רחוב
- כתובת חלקית

✅ **תמיד לרשום:**
- רחוב + מספר
- עיר
- מיקוד (אם יש)

---

### 3. קישורים למפות (אופציונלי):

אם רוצים קישורים ישירים, אפשר להוסיף:

**Google Maps:**
```
https://www.google.com/maps/search/?api=1&query=רחוב+הפרחים+15+כפר+תבור
```

**Waze:**
```
https://waze.com/ul?q=רחוב+הפרחים+15+כפר+תבור
```

**טיפ:** אם לא מוסיפים קישורים, הסוכן יוצר אותם אוטומטית מהכתובת!

## 🔍 איך לבדוק שהכתובת נשמרה?

### דרך Admin Panel:

1. פתח `tools/features_picker.html`
2. Admin Panel → Cabins
3. חפש את הצימר
4. בדוק שדה "Address" או "כתובת"

### דרך SQL:

```sql
SELECT 
    cabin_id_string,
    name,
    address,
    street_name,
    city,
    postal_code,
    google_maps_url,
    waze_url
FROM cabins
WHERE cabin_id_string = 'ZB01';
```
