### 2. הוספת "ליאה" לרשימת שמות צימרים ⚠️

**קובצים:**
- `src/agent.py` - `extract_cabin_id()` function
- `src/api_server.py` - cabin name matching

**שינוי:**
```python
cabin_names = {
    'מורן': 'ZB03',
    'מורני': 'ZB03',
    'יולי': 'ZB01',
    'אמי': 'ZB02',
    'ליאה': 'ZB04',  # ⚠️ צריך לוודא שזה מספר נכון!
}
```

**⚠️ חשוב:** צריך לוודא ש"ליאה" זה באמת ZB04. אם זה מספר אחר, צריך לעדכן!

**איך לבדוק:**
1. פתח Google Sheets
2. חפש את הצימר של ליאה
3. בדוק מה המספר שלו (cabin_id_string)
4. עדכן את הקוד אם צריך

**שינוי:**

```

**אחרי:**
```

### 1. מספר הצימר של "ליאה"

### 2. תמונות לא מוצגות

**סיבות אפשריות:**
1. אין תמונות ב-Google Sheets (עמודת `images_urls` ריקה)
2. אין תמונות בתיקיית `zimmers_pic/{cabin_id}/`
3. כתובת תמונה לא נכונה

**איך לבדוק:**
1. בדוק ב-Google Sheets אם יש כתובות תמונות
2. בדוק בתיקיית `zimmers_pic/` אם יש קבצי תמונות
3. נסה לפתוח את כתובת התמונה בדפדפן
