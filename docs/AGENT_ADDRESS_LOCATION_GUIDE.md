## 📝 איך לרשום כתובת ב-Google Sheets

### ✅ שיטה 1: כתובת מלאה (מומלץ)

**עמודה:** `address` (או `Address`)

**פורמט:**
```
רחוב + מספר, עיר, מיקוד
```

**דוגמאות:**
```
רחוב הפרחים 15, כפר תבור, 15247
דרך הגליל 42, צפת, 13100
שדרות הרצל 8, תל אביב, 61000
```

---

### ✅ שיטה 2: שדות נפרדים (גמיש יותר)

**עמודות:**
- `street_name` (או `Street name + number`) - "רחוב הפרחים 15"
- `city` (או `City`) - "כפר תבור"
- `postal_code` (או `Postal code`) - "15247"

**יתרונות:**
- הסוכן בונה כתובת מלאה אוטומטית
- נוח למיון/סינון לפי עיר

---

### ✅ שיטה 3: כתובת + קישורים ישירים (הכי מומלץ)

**עמודות:**
- `address` - כתובת מלאה
- `google_maps_url` - קישור Google Maps (אופציונלי)
- `waze_url` - קישור Waze (אופציונלי)

**דוגמה:**
```
address: "רחוב הפרחים 15, כפר תבור, 15247"
google_maps_url: "https://www.google.com/maps/search/?api=1&query=רחוב+הפרחים+15+כפר+תבור"
waze_url: "https://waze.com/ul?q=רחוב+הפרחים+15+כפר+תבור"
```

**טיפ:** אם אין קישורים, הסוכן יוצר אותם אוטומטית מהכתובת!
